# 喵不可罐：美術方向

風格名稱：**手繪童話感的奇幻 3D**（Painterly Storybook Fantasy 3D）

形狀圓潤、輪廓清楚，家具和建築有輕微彎曲與不對稱。材質是霧面，以大色塊和柔和明暗為主，看起來像手工做的，不是亮面塑膠玩具。環境陰影偏青綠，用局部暖金燈光引導探索。整體可愛、神祕、溫暖，帶一點荒謬。

參考圖只取方向：森林樹屋圖取氣氛與用色，低多邊形露營圖取「簡化幾何、清晰輪廓」，工業場景圖只取前中後景層次、逆光與遮擋。不複製任何參考圖的角色、建築配置、文字或介面。

## 光與可讀性

- 只有主罐、啟用中的貓縫、重要互動物會發光。
- 會照亮周圍的點光源全場最多 6 盞，「減少特效」模式一盞都不建；小燈用自發光材質代替。
- 窗戶光用半透明光片，只落到檯面，不落在狗的巡邏路線上。
- 家具底下要看得到貓和地面，不用大面積黑暗掩蓋模型。

## 角色

- **咪嚕**：精緻手作公仔的等級。
  - 身體是一整條車床曲線（臀部→腰→胸→往上彎的脖子），臉稍微壓平。毛色、背上三道斑紋、額頭細紋都畫在頂點顏色上。
  - 大眼睛帶兩個高光，有吻部、粉紅鼻子、鬍鬚、腮紅。
  - 外圍一圈深色描邊（反向外殼），從背後也一眼認得。
  - 尾巴是連續彎管：走路翹高捲成問號、輕腳時壓低、被追時炸毛、坐下時繞到身體側邊。
  - 姿勢：停下約 1.4 秒會坐下；起疑、被追或輕腳時壓低身體；走路時身體有起伏。耳朵在起疑和被追時往後貼。
  - 三種體型（普通、迷你、巨大）是同一個模型縮放，配色不變。
- **狗**：用圓角方塊組成方正輪廓，和貓的軟圓形成對比。表情認真（有眉毛）但帶喜劇感。工具用童話式的誇張比例，例如巨大膠帶捲、手提燈。帽子和徽章都是原創設計（毛線帽、魚骨徽章），不用任何既有制服的配色或標誌。

## 貓縫

貓縫是被貓爪抓開的柔軟布料裂口，不是科幻傳送門。五種狀態靠**造型**區分，不只靠顏色：

| 狀態 | 造型 |
|---|---|
| 可連接 | 浮著的奶油色魚骨，地上一圈慢轉的薄荷青縫線虛線 |
| 預覽（畫縫中） | 兩個縫點之間拉起一條弧形針腳線；不合法時針腳變成珊瑚紅叉叉，魚骨放大快轉 |
| 啟用 | 直立的深色夢境布料裂口，十字縫線邊，三個魚骨記號；建立時像拉開拉鍊（表面皺起、拉鍊頭往下滑），關閉時像重新縫合 |
| 施工封鎖 | 膠帶從中間慢慢貼開，上方掛施工三角牌 |
| 已封鎖 | 整個 X 形膠帶，上方掛禁止牌，魚骨變灰並下沉 |
| 被擦掉 | 魚骨變灰，周圍有水滴 |

## 其他關卡（已換配色、材質與粒子；沒有像廚房那樣重做家具）

- **洗衣宇宙**：靛藍水色、奶白泡泡往上飄、柔紫襪子礁、暖色安全燈。
- **夢境博物館**：深藍綠牆面、舊木地板與黃銅、琥珀展櫃小燈、紫色夢境亮點閃爍、牆頂藤蔓。
- **天空市場**：青綠與奶油色攤位頂棚、暖色布旗、倒落雨線、漂浮雲塊、斜飄的花瓣。
- **罐頭月亮、逃亡段**：霧面錫銀牆面與石板地、奶油月色、靛藍背景、柔金邊條、星塵。場地中央刻意不加光柱，以免蓋住總督的招式預告。

## 特效

- **輝光（Bloom）**：門檻 0.88，只有夠亮的自發光物件（主罐、貓縫、燈籠、展櫃燈）會暈開。「減少特效」和手機上不開。
- **假體積光**：光柱上亮下淡、帶直向光束紋，地上一圈柔邊光斑，光裡飄著灰塵。
- **環境粒子**：灰塵慢飄、泡泡上升、夢境亮點閃爍、花瓣斜飄、星塵。「減少特效」時數量剩三分之一。

所有關卡要看起來屬於同一款遊戲：不能一關低模、一關寫實、一關平面插畫。

## 技術約定

- 貼圖全部是程式用筆刷筆觸畫的 256px 圖（灰泥、木紋、地板、石板、錫面、漩渦、編織、布紋、魚骨毯），顏色由材質決定，沒有外部美術素材。各關可在 `pal` 用 `wallTex`、`floorTex`、`blockTex` 指定，圖例的單一格子用 `tex`。
- 輝光用的後製腳本是 Three.js r128 官方範例，放在 `lib/`，離線也能用。
- 圓角方塊幾何依尺寸快取重用；只是裝飾的物件不加碰撞。
- 關卡圖例只換模型欄位（`m`），種類、高度、底部離地、是否擋視線（`k`、`h`、`lo`、`see`）不動，碰撞和狗的視線才不會被美術調整影響。
